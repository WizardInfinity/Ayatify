Tentang Ayatify

Ayatify adalah platform baca Al-Qur'an online yang ringan, responsif, dan dapat dipasang sebagai aplikasi di ponsel maupun desktop.

Teks Arab, transliterasi latin, terjemahan Kemenag, tafsir, dan audio murottal disediakan oleh API publik EQuran.id. Ayatify tidak menyimpan data Al-Qur'an sendiri — semua diambil langsung dari API tersebut.

Data pribadi kamu (bookmark, terakhir dibaca, dan pengaturan) hanya disimpan di perangkatmu sendiri lewat localStorage browser, tidak dikirim ke server mana pun.

Fitur jadwal sholat masih dalam pengembangan dan akan hadir pada pembaruan berikutnya.
